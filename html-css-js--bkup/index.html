📘 ２メガ未満稼働前発電所に対するご提案

🔝 TOPへ

お手元のＩDの事業化推進や諸問題の解決を図ります！

拝啓　時下ますますご清栄のこととお慶び申し上げます。

さて、木質バイオマス発電事業は、ＩDを取得しても諸問題からプラント建設が進まず、ＩD期間の短縮に追い込まれるケースも少なくありません。

脱炭素社会において、このような事態は避けるべきです。
弊社は長年の再エネ事業経験と、ドイツの画期的木質バイオマス「ガス化炉」技術を活かし、ＩD買取や事業再構築など諸問題解決をサポートします。

特に、設備設置用土地問題や燃料供給問題がなければ、事業の具体化はスピードアップ。地方林業の活性化にも貢献できます。

弊社の理念「結い（ゆい）」は、皆で協力して物事を成し遂げる意味。秘密厳守で対応しますので、お気軽にお電話やメール（ID ご記入後）でご相談ください。

📘 個人情報保護方針（Privacy Policy）

🔝 TOPへ

当団体では、活動において取得する個人情報について、以下の方針のもと適切に取り扱い、保護に努めます。

  • 1. 個人情報は、会員管理、イベント案内、問い合わせ対応など、正当な目的の範囲内で利用します。
  • 2. 取得した個人情報を第三者に提供・開示することはありません（法令に基づく場合を除く）。
  • 3. 個人情報は、漏えい・紛失・改ざん等がないよう、安全に管理します。
  • 4. 本人からの情報の開示・訂正・削除の希望には、速やかに対応いたします。
  • 5. 個人情報保護に関する法令を遵守し、必要に応じて本方針を見直します。
